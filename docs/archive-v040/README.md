# 무협생활 · 플레이 가능한 통합 프로토타입 v0.4.0

[index.html](index.html)을 Edge 또는 Chrome으로 열면 플레이할 수 있습니다. 설치와 빌드가 필요하지 않습니다. 전달된 v0.3.2의 서사 확장에 시트 V-016~V-023과 조사 반영안의 초기 구현을 통합했습니다.

이름만 입력하면 성씨·출생·가족·고향·재능을 추첨합니다. 어린 시절을 지나 8세부터 삶을 선택하고 사망 후 일대기를 남깁니다. 무공 없는 민초의 삶도 온전한 경로입니다.

## 플레이

1. 계획에서 사계절의 주요 행동을 하나씩 배치합니다. 1배속 1년은 12초이며, 계획은 해마다 반복합니다. 지난 계절을 바꾸면 다음 해부터 적용합니다.
2. 무학·생업·휴식·교류를 조합하세요. 전념하면 피로가 쌓이고 휴식과 교류가 회복에 도움이 됩니다. 교류할 인연은 직접 정하거나 자동 추천에 맡길 수 있습니다.
3. 소문 목록에서 따라갈 소문을 선택합니다. 이동이 필요하면 여비·일정을 확인한 뒤 예약합니다. 새로운 소문이 나와도 이전 소문은 기한 안에 추적할 수 있습니다.
4. 중요한 사건과 전투에서는 시간이 멈춥니다. 상황별 2~4개 사건 선택과 다섯 전투 대응을 제공합니다. 선택의 당사자와 약속이 훗날 돌아올 수 있습니다.
5. 입문하면 수련 중심 일정으로 바뀌고, 확인하거나 직접 계획을 수정할 수 있습니다. 생업·이탈·전향은 계속 자유롭게 선택합니다. 무관에는 전수 허가, 독립 문파에는 독자 무학이 필요합니다.
6. 상세에서 능력의 효과와 성장법, 배운 심법·무공, 여섯 생업과 상태·업적을 살펴봅니다. 사망하면 작별 연출 뒤 인연과 선택을 잇는 일대기를 읽고 내보낼 수 있습니다.

출생 6종·생업 6종·문파 8곳·거점 9곳·선택 사건 정의 120종입니다. 모든 사건을 한 판에 강제하지 않습니다. 60세 고정 사망이나 민초 실패 결말은 없습니다.

## 저장

브라우저 로컬 저장과 JSON 내보내기/불러오기를 지원합니다. 새 삶을 시작하면 이전 삶도 별도로 보관합니다. 설정에서 이전 삶을 열 수 있습니다. 브라우저·폴더를 옮길 때는 저장 파일을 먼저 내보내세요.

v0.3.0·0.3.1·0.3.2를 이행하며 이름·재산·로그·선택·무학을 보존합니다. v0.3.2의 문장 기억·대기 중 연계 사건·분기·선택·전투도 유지합니다. 자동 이행 전 원본은 버전별 백업 키에 보관합니다. 같은 버전·시드·선택은 저장 복구와 배속에 독립적이며, 버전이 다른 미래 결과는 달라질 수 있습니다.

## 구현 파일

`story-pool.js`는 전달본의 원창작 소재집입니다. `engine.js`는 생애·수치·사건·관계·기억을 계산합니다. `game.js`와 `feedback-ui.js`는 기존 UI와 입력·시간·저장을, `life-panels.js`와 `life-panels.css`는 새 상세·소문·회고·작별 화면을 제공합니다. 원래의 삽화와 미술 방향을 유지합니다.

NPC는 소규모 역할 모형이며 조직 운영은 단순화되어 있습니다. 개별 무공별 숙련, 장편 환자·거래·가족 서사, 전체 계보와 대규모 외교·전쟁 AI는 후속 범위입니다. 정확히 같은 문장 재사용 검사와 실제 플레이에서 느끼는 의미상 반복은 구분합니다. 실제 독서·계획·열람 시간에 따라 한 판이 30분을 넘을 수 있습니다.
