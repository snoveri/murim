# 남은 작업 v0.4.2

P0: 현재 재현된 저장 손상·선택 중복·비무 사망·화면 가로 넘침은 없다. 실제 사람이 플레이한 의견은 자동 검사와 별도로 받는다.

P1:

- 추가18소속의 장기 성장·수장 취임·이탈을 기존8문파와 같은 규모로 비교한다. 현재 모든 소속의 입문·기초 사건과 26×200 심사,5가문 가주 및 군부/상단 경로를 확인했지만26소속의 완전한 지도층 생애 실험은 하지 않았다.
- 신규 본산 지도와 각 문파의 고유 절학·독·암기·진법을 설계한다. 현재 기획된 세력만 추가했고 기존9거점의 연락소로 접근한다. 임시 기초무학을 유명 절학 완성으로 표시하지 않는다.
- 과거 NPC의 미기록 혈연과 입양·가산·상속 규칙을 확정한다. 이름만으로 혈족을 만드는 방식은 제거했다. 새 자녀는 부모 관계를 기록하며 실제 후계 지정은 별도다.
- 개별 무공 XP를 도입할 경우 기존 공통 XP 분배와 저장 이행부터 결정한다. 성장·수명·심법 손실·경제의 충돌 가안을 일괄 적용하지 않는다.

P2:

- 분쟁을 공성·병력·장기 외교·점령 경제로 확장할지 별도 기획한다. 현재3개 전쟁 조합·7개 관점·참전/구호/중재/불참·휴전/복구의 이벤트 모형이다.
- 실제 모바일 기기, 키보드·스크린리더, 장시간 인간 플레이로 읽기 속도와 체감 사건 빈도를 점검한다.

사용자가 확정한 방향: 마교·혈교는 악의 세력이되 개인의 선택은 유지한다. 명령 거부·포로 구출·탈퇴는 현재 선택지로 연결돼 있다.
