# 플레이테스트 피드백 반영 · v0.4.0

2026-10-22. 전달받은 v0.3.2의 서사 확장을 보존하여 V-016~V-023과 자료조사 반영안의 첫 구현 범위를 통합했다. 이전 피드백과 사용자 답변은 [v0.3.1 기록](PLAYTEST-FEEDBACK-v031.md)에 보존한다.

| 항목 | 반영한 동작 | 검증 |
| --- | --- | --- |
| V-016 | 혈연 가문과 전수 출처를 한국어 이름으로 표시. 남궁 직계가 본가에서 배우는 신분과 외성 문하를 구분 | 실제 직계 출생·입문·상세 화면 검사 |
| V-017 | 기본·능력·무공·생업·상태·업적을 재구성. 심법은 무공에 통합. 레이더는 능력에만 표시하고 전 능력의 수치·효과·성장법 제공. 무학·생업·업적은 목록을 눌러 설명 확인 | 7개 상세 탭 × PC/모바일 및 선택 입력 검사 |
| V-018 | 중복 sidebar 위치 표시 제거. 메인 위치·음향 기능 유지 | DOM 및 입력 검사 |
| V-019 | 생업·수련의 피로 누적과 자동 회복을 분리. 휴식·교류의 효용 보존. 성장 계수를 함께 조정 | 행동별 120시드의 3년 연속 행동과 전체 생애 실험 |
| V-020 | 유효 소문 최대 6개를 모두 표시. 기존 소문 선택 유지. 총 8계열 및 먼저 가져감·미발견·헛소문·당사자 부재·기한 경과의 5개 종료 사건. 이동 질문에서 비용과 이동·추적 일정 표시 | 새 소문 후 옛 소문 추적, 중복 보상, 기한·장소 검사 |
| V-021 | 이름·나이·사인·삶의 활동 비중·명성·은거를 반영한 작별 연출 뒤 일대기 표시. 건너뛰기와 동작 줄이기 지원 | 실제 사망 → 작별 → 결과·기록 및 포커스 복구 |
| V-022 | 입문 뒤 수련·내공·임무 중심으로 미래 계획 전환. 청원 비활성화. 확인/계획 수정 선택 제공 | 실제 입문·계획 전환·기존 저장 보정 |
| V-023 | 상황별 2~4개 선택. 원본 8쌍 보존, 추가 사건 묶음과 실제 인물·원인·약속을 잇는 후속 사건 | 원인·당사자·사망/이동·저장·중복 처리 검사 |

자료조사 C01~C24는 최소 적용 범위를 중심으로 연결했다. 관계 대상 지정, NPC 생업/무학 성장 분리, 지역 작황·분쟁·복구, 네 사건 묶음, 여덟 문중의 생활 사건, 사부 유형·전수 재심, 제한된 무학 특성, 첫 전수와 은거 서신, 수장의 중재·후계, 선택을 잇는 회고를 제공한다. 직업의 대표 환자·작업·거래를 장편 개인 서사로 전개하는 부분과 개별 무공 숙련 축은 후속 범위다.

현재 검증 수치와 한계는 [통합 보고서](INTEGRATION-v040.md), [밸런스](BALANCE.md), [검증 원본](verification-v040.json)에 기록한다.
