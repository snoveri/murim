## 자체 창작으로 고정한 세계

- 왕조는 **대연**, 연호는 **승평**. 실존 왕조와 연대를 맞추지 않는다. 새 삶은 승평122년에 출생하며8세 직접 조작은130년부터다. 과거 저장의 연도는 보존한다.
- 중원·관중·강남·호북·서남·새외의 9개 거점을 사용한다. 지도는 가상 강호의 개략도다.
- 소림사·무당파·화산파·남궁세가·개방은 장르 소재를 본작 규칙으로 재구성했다. **흑사방·천산마교·혈교의 구체 조직과 사건은 자체 창작**이다.
- 최신 피드백과 사용자 확정에 따라 마교·혈교는 납치·강제 포교·약탈을 벌이는 악의 세력이다. 개인의 선택은 유지하며 플레이어는 명령 거부·포로 구출·탈퇴를 선택할 수 있다. 정파·사파의 모든 개인을 소속만으로 선악 고정하지 않는다.
- 관부는 구휼·납세·분쟁 해결에 관여한다. 강호의 명망이 국가 법질서를 자동으로 무효화하지 않는다.
- 냥은 게임 회계 단위다. 실존 시대의 임금·물가·동전과 은의 환율을 재현했다는 뜻이 아니다.
- 성인 기준 18세, 유년 보호, 혼인의 쌍방 동의, 자녀 선택은 본작의 플레이 규칙이다. 특정 시대의 역사적 제도를 그대로 옮긴 것이 아니다.
- 선협의 영근·영석·원영·천겁·비승·선계는 사용하지 않는다. UI의 능력치는 세계 안에 보이는 시스템창이 아니다.

[공식 개파 서사 자료](https://xa.wanmei.com/history/his_cont_08.htm)는 비급의 이해와 독자 무학이라는 장르적 맥락의 참고 자료다.

화산파의 **이십사수매화검법**은 사용자의 지정과 한국 무협의 관습을 본작에 채택한 명칭이다. 모든 작품에 통용되는 역사적 정설이라고 주장하지 않는다. 남궁의 창궁무애검법, 소림의 금강복마권, 무당의 태극검법, 개방의 타구봉법도 본작의 전수 목록으로 고정했다. 흑사방·천산마교·혈교의 비전 명칭은 자체 창작이다. 인물 화면에는 초식·운기·조식·행공·내력·내상·주화입마·비무·생사결·녹림·표행·사승·진전·직전제자·개파·은거의 16개 용어 풀이를 둔다.

## 서로 분리해 저장하는 자격

| 항목 | 저장 내용 | 자동으로 생기지 않는 권리 |
| --- | --- | --- |
| 혈연 | 출생 부모 ID, 성씨, 가문, 직계 여부 | 문파 직위·전체 무공 |
| 후견 | 보호자 ID | 혈연·성씨 변경 |
| 사승 | 사부 ID와 과거 인연 | 가문의 혈족 상속권 |
| 소속 | 현재 문파·과거 소속 이력 | 직업 변경·현재 심법 변경 |
| 제자 신분 | 문파별 문하/방도/교도/직전제자 | 진전·후계·장문직 |
| 전수 | 배운 무공, 현재 문파 진전 상태 | 무공의 완성·다른 심법과의 무손실 융합 |
| 직위 | 교관·장로·수장·연합 지도자 | 경지·내공의 자동 증가 |

남궁세가의 외성 제자는 가주가 될 수 없다. 다른 문파의 수장과 무림맹주·사도련주·천마·혈마의 자격에는 출생 가문 제한을 두지 않았다. 입문·기초 지도·공적·전수·정치적 지지를 쌓아야 한다.

소림은 속가 경로를 구현했다. 모든 문파에 외문→내문→직전의 단일 명칭을 강요하지 않는다. 본작의 직전제자는 최고 제자 신분이며 진전은 별도 전수다.

독립 문파는 직접 창시한 상승무공 또는 해독·습득을 마친 잊힌 무공으로 사승의 맥을 세워야 한다. 기존 문파의 비전과 전수 허가만으로 독립 문파를 만들 수 없다. 무관은 선택한 무공의 전수 허가가 있으면 개설할 수 있다. 공개 기초 무공은 공개 전수 범위를 기본 허가로 취급하고, 문중 무공은 신뢰와 공헌을 쌓아 별도로 허가받는다. 상단·의방·공방 등 민간 조직은 직업적 기반으로 운영한다. 고위 문인이 탈퇴하면 과거 문중의 불신과 명망 손실이 기록된다.

## 생애에서 지키는 일관성

- 0~7세는 자동 회고하며, 보호자가 없는 아이는 구휼과 후견으로 생존한다. 8세부터 직접 조작한다. 유년 사망은 이번 버전에서 보호한다.
- 문파를 떠나거나 문파가 해산되어도 성씨·혈연·배운 무공·현재 심법은 삭제하지 않는다. 현재 소속에서의 권한과 과거의 배움은 구분한다.
- 소속 변경과 심법 변경은 다른 선택이다. 이미 내공을 쌓았다면 새 심법을 받을 때 호환성과 손실·내상 위험을 확인한다.
- 비급은 발견, 연구에 의한 해독, 전환 선택을 거친다. 소지만으로 내공이 생기지 않는다. 기존 심법을 유지하고 초식 지식만 얻을 수도 있다.
- 혼인과 자녀는 플레이어의 동의와 상대의 성인 여부·생존·호감·기혼 상태를 검사한다. 혼인 이후의 갈등·사별·관계 정리와 새 인연이 가능하다.
- 부모는 서로의 배우자로 연결하며, 상대가 사망하면 사별 상태를 표시한다. 35세부터 혼인 제안 확률을 크게 낮추며, 자녀 제안은 두 배우자 중 나이가 많은 쪽을 기준으로 줄어든다. 이 연령 곡선은 요청한 시대감과 플레이 길이에 맞춘 게임 규칙이다.
- 분기 중 두 차례 개인 이야기를 기록한다. 소문은 발견 장소·기한·진위를 가지며, 해당 지역에서 추적하면 후속 선택 사건으로 이어진다. 거짓 소문이나 기한이 지난 소문도 존재한다.
- 축적 내공과 가용 내력을 별도로 저장한다. 전투는 가용 내력을 쓰고, 휴식·시간 경과로 회복한다. 전력 또는 강행 대응으로 무리한 운기를 하여 내상을 입었을 때만 축적 내공을 잃을 수 있다. 비무 패배는 사망을 발생시키지 않는다.
- NPC는 고유 ID를 유지하며 분기별 목표에 따른 숙련, 연간 혼인·나이·사망을 갱신한다. 사망한 인연도 기록에서 삭제하지 않는다.
- 중요한 선택 중에는 플레이어·NPC·세계·사망 판정이 함께 정지한다. 동일 사건의 같은 선택은 한 번만 반영한다.
- 수명은 60세에 고정하지 않는다. 연령·건강·부상·내공과 난세의 위험을 반영하며, 최종 안전 상한은 105세다. 사망 후 일대기·선택·전승과 남긴 재산을 표시한다.
- 평온·가족·직업·전승·재산·무학·직위를 별도로 기록한다. 하나의 총점이나 민초 실패 엔딩을 만들지 않는다.

## 프로토타입의 구체적 범위

실제 플레이는7가구·5혈연가문·6생업·26소속·9거점·189선택사건을 사용한다. 새 소속은 기존 거점의 연락소로 지원하며 독립 본산·고유 절학·가산 운영은 후속이다. 기본 생업·가족·무학·창업·승계와 죽음까지 연결했다. 사건 수는 한 생애에 반드시 발생하는 횟수가 아니다. 반복 가능한 개인 이야기와 다섯 전투 대응은 사건 정의 수에 합산하지 않았다.

NPC 목표는 소규모 집계 규칙이며 완전한 효용 AI가 아니다. 조직 경영은 개인/조직 금고와 손익의 간단한 모형이다. 유명 인물 6명의 장편 개별 서사, 상세 가족 계보 편집, 모든 문파·무기 계열, 실제 전쟁과 외교의 대규모 시뮬레이션은 후속 범위다. 전투는 별도 화면에서 정보를 확인하고 다섯 대응을 선택하는 결산 방식이며, 도주 실패 시 다시 대응한다. 소문은 비급·의원·무인·거래·구휼·끊긴 안부·길목 시비·배움의 여덟 계열을 제공한다. 유효 소문 여섯 개를 동시에 보관하며, 먼저 가져감·미발견·헛소문·당사자 부재·기한 경과를 구분한다. 생성된 초상·풍경은 기존 시제품의 임시 자산을 사용한다.


## v0.4.0의 관계와 서사

전달된 v0.3.2의 원창작 소재집과 8쌍 사건을 유지한다. 새 사건에는 당사자 ID·원인·선택·약속·후일담을 저장한다. 역할이 필요한 익명 표사·문인은 새 인물로 만나며 기존 농부를 임의로 무인으로 바꾸지 않는다. 사망한 당사자의 후속은 기록과 서신으로 바꾼다. 교류는 선택한 한 인연에게 적용하며 거리가 멀면 서신으로 구분한다. 지역 작황·길목 분쟁·복구는 생업 수입과 부탁의 조건에 반영된다.

문파 위기는 경고 뒤 시간이 지나 해산 또는 수습된다. 남궁 직계의 본가 수학과 외성 문하를 구분하며 혈연·후계·전수·직위는 별도다. 사부는 엄격/배려 두 유형과 서로 다른 전수 준비 조건을 갖고, 거절 뒤 재심을 청할 수 있다. 사부 부재에도 기존 무학을 연마하고 원로 심사를 받을 수 있다.

현재 새 내용은 프로토타입의 초기 범위다. 전투는 결산 방식, NPC는 역할별 두 성장 축, 문파/조직 운영은 간단한 재정·중재·후계 사건으로 제한한다. 장편 환자·거래·가족 서사와 개별 무공 숙련·전체 외교/전쟁 AI는 후속이다. [통합 내역](INTEGRATION-v040.md)에 보존·변경·검증 범위를 정리했다.
