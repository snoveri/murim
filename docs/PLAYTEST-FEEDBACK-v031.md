## 사용자 답변으로 확정한 두 가지

1. **독립 무학 조건은 독립 문파에 적용한다.** 무관은 기존 무공의 전수 허가를 받으면 운영할 수 있다. 상단·의방·공방 등 민간 조직은 직업적 기반으로 운영한다.
2. **가용 내력은 소모 후 회복한다.** 축적한 갑자는 평상시 전투 소모량이 아니다. 전력·강행 대응으로 무리한 운기를 하여 내상을 입었을 때에만 일부 손실될 수 있다.

무관의 공개 기초 무공은 공개 전수 범위를 기본 허가로 취급한다. 문중 무공의 전수 허가는 현재 소속의 신뢰 65·공헌 60 이상에서 청원하며, 승인 시 공헌 20을 사용한다. 허가와 독자 무학의 정통성은 별도로 저장한다.

## 플레이에서 확인하는 방법

1. [게임 열기](../index.html). 연대기에서 진행을 누르면 분기 안에서 개인 이야기가 바뀌며 발자취가 쌓인다. 나이를 확인하고 새해 알림을 본다.
2. 계획에서 이미 지난 계절을 바꾸면 다음 해 줄만 변경된다. 무소속일 때 입문 계획을 선택하고, 입문 후 버튼 상태를 확인한다.
3. 소문이 생기면 적힌 장소로 이동하고 소문 추적을 예약한다. 비급은 발견 후 연구를 마쳐야 독자 무학의 기반이 된다.
4. 비무 또는 위험한 상대와의 전투에 응하면 전투 화면이 열린다. 상대 정보, 가용 내력, 대응별 위험을 보고 선택하고 결과를 확인한다.
5. 인물 → 용어에서 무협 용어를, 계획의 설립 영역에서 무관·개파 조건을 확인한다.

## 검증과 결과

- 회귀 검사 **75개 통과, 실패 0개**. 실제 UI 입력, 요소 유지, 저장 이행, 이야기, 소문, 설립 조건, 전투를 포함한다.
- 같은 `engine.js`로 표준 **10,008회**와 지도층 집중 **1,152회**, 합계 **11,160회** 전 생애를 실행했다. 지정한 저장 유효성·무공 강제 유입·기록 역전·중복 반영·미종료 검사 위반은 0건이다.
- PC 1366px·모바일 390px에서 8개 기본 화면과 전투 화면의 **18개 배치**에 가로 넘침이 없었다. 1920px 연대기도 캡처했다. PC·모바일 전투 캡처는 직접 확인했다.
- 표준 실험의 사망 연령 중앙값은 75세다. 1배속 진행과 선택당 12초를 가정한 생애 시간은 중앙값 **19.0분**, 90백분위 **23.0분**이다. 실제 독서·계획·이동 화면 체류에 따라 더 길어질 수 있다.
- 민초 정책은 생애 내내 내공·무공 경험치가 0인 경로를 유지했다. 고아를 포함한 모든 출생에서 지도자 사례를 확인했다. 이 결과가 모든 플레이 방식의 난이도나 전역 최적 밸런스를 증명하는 것은 아니다.

현재 수치·실험 조건은 [BALANCE.md](BALANCE.md), 검사 원본은 [.qa/report.json](../.qa/report.json), 시뮬레이션 원본은 [표준](balance-report.json)·[지도층](leadership-study.json)에 있다.

## 저장과 구현 위치

v0.3.0 저장은 이름·진행·재산·선택·시드를 유지하며 v0.3.1로 이행한다. 자동 이행 전 브라우저에 원본 백업을 남긴다. 새 분기 이야기·가용 내력·소문·권한 필드는 기본값으로 추가한다. 전투 도중과 결과 확인 대기 상태도 저장한다. 같은 버전의 복구는 같은 결과를 내며, 업데이트로 규칙이 바뀐 뒤의 미래까지 과거 버전과 같게 고정하지는 않는다.

- [engine.js](../engine.js): 이야기·소문·가족·무학·권한·전투·저장 이행
- [feedback-ui.js](../feedback-ui.js): 요소를 유지하는 갱신, 계획·전투·설립·용어 화면
- [feedback.css](../feedback.css): 나이·새해 알림·전투·사이드바·모바일 표시
- [game-qa.js](../tools/game-qa.js): 회귀 검사
- [verify-ui.ps1](../tools/verify-ui.ps1): 브라우저 검사·시뮬레이션·화면 캡처

현재 소문 후속은 비급·의원·무인 세 계열이며 개인 이야기는 조건부 문장 조합 방식이다. 전투는 대응을 선택해 결산하는 구조다. 장편 사건 집필이나 초식별 턴 전투까지 구현한 버전은 아니다.
