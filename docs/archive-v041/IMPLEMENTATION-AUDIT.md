사용자가 지정한 UI_v2 폴더의 murim_prototype (2).zip 내부 v0.4.0을 기준으로 삼았다. 다른 폴더의 동명 ZIP은 v0.3.2여서 제외했다. 기준43파일의 ZIP 내부 해시와 작업본 해시가 모두 일치했으며 .qa/baseline-v040에 수정 전 파일을 보존했다. 기준 manifest는 baseline-v040-manifest.json에 있다. Git 저장소는 없으므로 커밋 대신 SHA-256을 사용했다.

기준 ZIP SHA-256: BCB90EDDD9ABBE6193E14D5C8F336B421AD9F9300F408B80BDCC474800FC80B2.

작업 전 기획 시트는63탭이었다. 메타데이터의 실제 grid 범위 안에서63탭 전체를 조회했고 실패한 탭은0이다. planning-snapshot-v041.json에 각 탭 ID·grid·읽은 범위·행 전체를 보관했다. 추가한42~45 감사 탭을 포함한 현재 탭 수는67이다. 원래63탭은 수정하지 않았다.

## 활성 실행 경로

index.html은 story-pool → birth-model → engine → game → life-panels → feedback-ui → dev-tools 순서로 defer 실행한다. game.js의 BaseViews를 feedback-ui.js가 참조하고 최종 render/navigate/choose/clock을 재정의한 뒤 부팅한다. dev-tools는 그 최종 render/settings/persist에 연결한다.

app.js, index.original.html, .qa 과거 스냅샷/브라우저 프로필, 구형 ZIP은 활성 실행 경로가 아니다. 과거 game.js 함수 본문과 현재 override의 차이를 UI 버그로 판정하지 않았다. 기존 서사 소재집과 삽화, 네 기존 CSS, feedback-ui.js는 보존했다.

## 미완료와 설정 충돌

충돌은 RULE-CONFLICTS.md 및43탭에 기록했다. 신규11건과 기존 CF-01~26 이행 판정을 연결했다. 출생·지역 가중치, 신규 가문의 자연 배분, 구형 연간/분기 성장·XP·심법 손실·노화/경제, 일반전 위험·상대 다축, 개별 무공 XP, 사부별 반복 부고, NPC 혈족 후계 판정을 임의 확정하지 않았다.

새 가문의 자연 출생 확장은 보류다. 일반 플레이는6종 18/28/18/16/12/8을 유지한다. 신규 가문·몰락 가구는 테스트 생성으로 검증한다. 가문 연고와 실제 출생/현재 거점은 구분한다. 새 가문의 독/암기/진법·전수 권한·가산 운영을 구현 완료로 기록하지 않았다.

표시만 구현3행은24_가문_세가의 본가/분가/인정 상태다. 저장·표시·테스트 생성은 있으나 별도 가산·분가 설립·권리/사건 판정은 없다. 원래 시트가 이를 구현 완료로 주장하지 않았으므로 허위 구현표기로 세지 않았다. 확인된 허위 구현표기는0이다.

미구현에는 배분·항렬·사형제 서열, 확장 친족/적서/비밀 혈통, 유명인6루트, 장비, 개별 외공/경공, 가주 전용 비급, 맞선·중매, 암살조직·개별 조직원, 비급 집필/개량, 전용 다단계 지도자/계승·완전 요인 실험 등이 포함된다. 행별 정확한 판정은42탭/CSV에 있다.

부분 구현에는 소규모 NPC 생애, 전체 unlockRules/정치 승인, 기본 조직 운영, 일반사건의 의미 있는 후일담, 창시·전승·무학 특성, 직업 대표 작업, 무림/민초 복수 성취가 있다. 이를 대규모 NPC AI·전체 외교/전쟁·장편 환자/계약·세대 운영의 완료로 보지 않는다.

확인불가12행은 사람의 체감 경험/시간·기억 가능성11행과 삽화/외부자료 전체 권리 확인1행이다. 소스 접근 실패로 남긴 탭은 없다. 정상 자연 도달성과 의미상 중복은 강제 이벤트 전수 검사만으로 증명되지 않는다.

## 계속 갱신할 자료
