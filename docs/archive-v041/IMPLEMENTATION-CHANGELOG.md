story-pool.js·기존 삽화·기존 CSS 네 파일·feedback-ui.js는 원본을 보존했다. 새 CSS는 개발 패널에만 적용한다. 기본 행동/경제/내공/노화 공식을 새 가안으로 치환하지 않았다. 직전/진전/후계, 가용 내력과 축적 내공의 분리를 유지했다.

추가 가문은 남궁·사천당가·하북팽가·제갈·모용이며 목록 근거는 02_세력문파!A13:E17이다. 황보·악가 등 교체 후보를 독립 가입 세력으로 임의 출시하지 않았다. 새로운 출생 프로필은 별도 ID를 사용하며 과거 noble은 남궁 본가 직계의 의미를 유지한다. 확장 가문의 자산/지원은 테스트의 기존 템플릿이며 최종 밸런스가 아니다.

대표 작업 기록은 앞으로 선택한 직업 사건부터 생성한다. 과거 로그에서 환자·계약·성과를 소급 창작하지 않는다. 의원 기록도 실제 치료 성공이나 환자 완치를 새 사실로 보장하지 않는다.

기존 릴리스142검사/11160생애 기록은 baseline과 archive에 보관한다. 최종 검증 집계는 QA-RESULT 및 verification-v041.json에 새로 기록한다. 테스트 실패는 검사를 삭제하지 않고 맥락 준비 오류와 실제 혼인 자격 누락을 구분해 수정했다.

일회성 백업/치환 도구는 작업 기록이며 배포 ZIP에서는 제외한다. 배포 실행은 빌드 없이 index.html로 유지한다. 새 코드에는 주석을 추가하지 않았다.
