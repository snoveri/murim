## 저장·테스트 격리

실제 설정 토글 진입/해제, 원본 상태 JSON 일치, 자동 저장 및 명시 저장의 원본 슬롯 보호, 새삶 보관 차단, 패널 닫기/배지 재열기, 스냅샷 UI 복구, 개발 예약의 스냅샷 왕복, 비활성 강제 API 거절을 검사했다. 명시 저장/스냅샷 테스트는 내려받기 함수를 가로채 내보낸 JSON을 확인하고 일반 슬롯을 대조했다.

v0.4.0 원본 엔진으로 분기 중간·대기 사건·비무 중·연쇄 예약 fixture4개를 만들었다. 기존 NPC·로그·재산·내공·이름·혈연·사건/전투/연쇄를 보존하고 결과가 한 번만 반영되는지 확인했다. noble 출생을 새 가문으로 재추첨하지 않는다. 신규 가족 그래프 변조도 거절한다.

## 사건·전투·출생 검사의 의미

120종268선택은 성인·자원·NPC·기억 등 유효한 테스트 맥락을 만든 뒤 실제 resolveEvent와 저장 이행을 사용했다. 비용 부족/자격 미충족 선택을 무조건 허용하지 않았다. 강제 혼인에서 플레이어의 성인·미혼 조건 누락을 발견해 보강했고, 이미 혼인한 성인 fixture는 실제 합의 이혼 사건을 거친 후 재혼 검사에 사용했다.

일반 발생 조건과 강제 발생을 분리해 정상 조건 불충족·쿨다운 보존도 검사했다. condition=false 자체는 도달 불가능의 증거가 아니다. 입문/돌파/부고/후속 등 예약 경로가 있으므로 별도로 기록했다. 모든 사건의 자연 도달성을 입증한 결과는 아니다.

전투는 기존 화면에서 다섯 대응을 사용하고 상대 NPC ID·관계·생존을 연결한다. 비무는 죽지 않는다. 일반 적대전과 생사결은 기존 lethal 공식을 공유하며 상대의 경지/내공/건강 등은 현재 관측 프로필이다. 단일 power 이외의 완전한 상대 공식이 구현되었다고 판정하지 않았다.

6000시드의 생성 수는 고아1099, 농가1627, 장인1063, 상인1008, 무인721, 기존 남궁 직계482다. 기존 가중치18/28/18/16/12/8을 보존한 표본이며 새 최적 확률의 승인이 아니다. 신규 가문/몰락 가구는 테스트 생성 경로로 검증했다.

## 현재 생애 분포

표준10,008회의 60세 생존률83.3%, 사망 나이 중앙76세였다. 전체 일생 중요 선택 중앙32회/P90 45회, 순수 진행 중앙13.6분이다. 선택당12초를 가정하면 중앙20분/P90 24.8분이다. 열람·계획 체류는 별도이며 실사용자 시간 실측이 아니다. 30분 강제 종료는 없다.
